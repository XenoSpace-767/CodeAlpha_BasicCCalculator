# Basic Calculator Program — C

A lightweight procedural C program that performs fundamental arithmetic operations (Addition, Subtraction, Multiplication, and Division) using switch-case conditional structures and standard input/output[cite: 5].

Developed as part of the **CodeAlpha C Programming Internship**[cite: 5].

## Features
* **Switch-Case Control Flow:** Selects arithmetic procedures cleanly[cite: 5].
* **Division-by-Zero Handling:** Prevents runtime crashes when dividing by zero.
* **Formatted Output:** Cleans floating-point calculations to two decimal places.
